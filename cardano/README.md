### Features

* Liabilities
* Bonds
* Hedge analysis


### Project Structure
```
project
│   README.md  
│   │   assignment.py
│   │   settings.py
│   │   test.py
```
Where:
* assignment.py is the main script
* settings.py contains a few variables that are used throughout the code
* test.py is the test script

### Instructions
The below assumes running the scripts on macOS.

To run the main script:

`python3 assignment.py`

To run the test scripts:

`python3 test.py`
